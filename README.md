# 🏢 Sistema de Gestão de Condomínio

Sistema web para gerenciamento e administração de condomínios residenciais, desenvolvido utilizando **Spring Boot, Angular e PostgreSQL**.

O objetivo do projeto é centralizar as principais atividades administrativas de um condomínio, facilitando a comunicação entre síndicos, administradores, funcionários e moradores.

O projeto será desenvolvido de forma incremental, começando com funcionalidades essenciais e evoluindo para recursos mais avançados.

## 🎯 Objetivo

Desenvolver uma aplicação web completa que permita:

- Gerenciar condomínios, blocos e unidades.
- Cadastrar e administrar moradores.
- Controlar visitantes e encomendas.
- Gerenciar reservas de áreas comuns.
- Publicar comunicados.
- Registrar e acompanhar ocorrências.
- Disponibilizar informações administrativas.
